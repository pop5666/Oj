# Budgie Spot the Difference (Ultra HD Edition)

เกมจับผิดภาพสุดท้าทายระดับโลก ด้วยเทคนิคการตกแต่งภาพในระดับพิกเซลผ่าน Canvas 

## 🌟 คุณสมบัติเด่น
- 3 หมวดหมู่หลัก (สัตว์, สถานที่ท่องเที่ยว, อาหาร)
- รวม 60 ด่านท้าทาย
- การดัดแปลงพิกเซลแบบ Seamless ลบและดัดแปลงวัตถุอย่างเป็นธรรมชาติ
- รองรับการแสดงผลบนสมาร์ทโฟนและเดสก์ท็อป (PWA Ready)

## 📁 โครงสร้างโปรเจกต์
- `index.html`: โครงสร้างหน้าเว็บหลัก
- `css/style.css`: สไตล์การจัดวางและดีไซน์ UI
- `js/game.js`: ระบบลอจิกเกม การวาด Canvas และการจับผิด
- `manifest.json` & `sw.js`: สำหรับรองรับการติดตั้งลงบนมือถือแบบ PWA
